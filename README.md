# Домашняя работа 4

## Условие задачи

Даны целые числа, указывающие число минут и часов (0–12). Вычислить время в минутах, когда часовая и минутная стрелки будут находиться на одной линии.

## 1. Алгоритм и блок-схемы

### Алгоритм:

1. Начало.
2. Объявить переменные:
- **h** — количество часов.
- **m** — количество минут.
- **a** — угол между часовой и минутной стрелками.
- **t** — время в минутах, через которое стрелки будут находиться на одной линии.

3. Ввести количество часов и минут.

4. Перевести часы в диапазон от 0 до 11.

5. Вычислить угол между часовой и минутной стрелками.

Минутная стрелка проходит 6 градусов за минуту, а часовая — 0,5 градуса за минуту.

Разница скоростей стрелок составляет 5,5 градуса в минуту.

6. Привести угол к диапазону от 0 до 180 градусов.

7. Составить условие при помощи операторов if и else.

Если стрелки уже находятся на одной линии, то время равно 0.

Если стрелки ещё не находятся на одной линии, вычислить время до следующего такого положения.

Условие проверки:

```c
if (a == 0)
{
    t = 0;
}
else
{
    t = (180 - a) / 5.5;
}
```

8. Вывести результат.
9. Конец.

## 2. Реализация программы

```c
#include <locale.h>
#include <stdio.h>

int main()
{
    setlocale(LC_ALL, "RUS");

    int h;
    int m;
    double a;
    double t;

    puts("Введите часы:");
    scanf("%d", &h);

    puts("Введите минуты:");
    scanf("%d", &m);

    h = h % 12;

    a = 6 * m - (30 * h + 0.5 * m);

    while (a < 0)
    {
        a = a + 180;
    }

    while (a >= 180)
    {
        a = a - 180;
    }

    if (a == 0)
    {
        t = 0;
    }
    else
    {
        t = (180 - a) / 5.5;
    }

    printf("Через %.2f минут стрелки будут на одной линии\n", t);

    return 0;
}
```
