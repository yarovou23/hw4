# Домашняя работа 4
## Условие задачи
Чтобы открыть портал, необходимо зажечь три древних кристалла. Кристалл загорается, если переданная ему энергия (A, B, C) кратна трем. Портал откроется только если загорятся все три кристалла. Запишите условие открытия портала.
## 1. Алгоритм и блок-схемы
###Алгоритм:
1. Начало
2. Объявить переменные:
- **A** — энергия, переданная первому кристаллу.
- **B** — энергия, переданная второму кристаллу.
- **C** — энергия, переданная третьему кристаллу.
3. Составить условие при помощи операторов if и else.
Кристалл загорается, если переданная ему энергия кратна трём.
Портал откроется только в том случае, если зажгутся все три кристалла.
Условие открытия портала:

```c
(A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0)
```
